# 🌱 EcoVerde

## Sobre el proyecto

EcoVerde es un proyecto web educativo desarrollado para promover
hábitos de consumo responsables y el cuidado del medioambiente.

La página presenta diferentes productos sustentables y busca demostrar
cómo pequeñas decisiones cotidianas pueden contribuir a un futuro más
amigable con el planeta.

## Tecnologías utilizadas

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Google Fonts
- Formspree
- GitHub Pages

## Características

El sitio cuenta con:

- Estructura semántica HTML.
- Barra de navegación interna.
- Sección de presentación.
- Información sobre el proyecto.
- Contenido multimedia mediante iframe.
- Cards de productos organizadas con Flexbox.
- Sección de reseñas organizada con CSS Grid.
- Formulario de contacto funcional mediante Formspree.
- Diseño responsive para computadoras, tablets y celulares.
- Estilos CSS externos.
- Google Fonts.
- Background con imagen y degradado.
